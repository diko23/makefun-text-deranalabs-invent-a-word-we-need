Entry for the [Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0) competition on make.fun.

## Overview

This program outputs a newly coined English noun and its concise, single-line dictionary definition describing the familiar awkward moment when two people say goodbye and immediately end up heading in the same direction.

## Run it

```sh
node main.ts
```

By default, `main.ts` writes the UTF-8 entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when `MAKEFUN_OUTPUT_DIR` is set), creating the directory if needed and setting file permissions to `0644`. The grader runs it as `node /bot/main.ts`.
